tokenradar is a token launch radar: it ranks 198 pre-token protocols by an implied value computed from the snapshot's own figures (TVL, seven-day growth, age with no token, chain breadth) and gives each one a concrete farm plan with costs and times. The board covers the full 40-protocol watchlist and adds 158 more launch candidates, 138 of them below the house's $50M floor.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
